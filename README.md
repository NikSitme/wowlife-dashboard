# WOWlife dashboard

[GitHub Pages](https://niksitme.github.io/wowlife-dashboard/)

Помeсячный P&L, ФОТ и финмодель читают CSV актуального листа «сборка ОПиУ_2» (gid 1095006698) основной выгрузки Адеска. Автоматическое обновление — при открытии страницы, ручное — кнопка «Обновить данные». Кэш прежнего источника не применяется.

Нижний P&L по умолчанию сохраняет строки, знаки и итоги Адеска; отдельный управленческий вид и карточки используют принятые корректировки. Источник, время получения и предупреждения отображаются рядом с таблицей. Формулы и источники описаны во встроенной документации.

Ценообразование разделено на «Услуги», «Наборы», «Новые наборы». Цена CRM сохранена отдельно от предложенной цены. Скидка, эквайринг, налог, упаковка и логистика наследуются из параметров; исключения строки сохраняются в браузере. Возвраты исключены из прайса. Логистика по умолчанию — расходы на доставку / выручка сайта за последние шесть месяцев ОПиУ. Группы финансовых столбцов сворачиваются, заголовки содержат подсказки. Расчёт маржи и целевой цены общий для услуг, наборов и их состава. Худший сценарий набора всегда берёт 100% активаций и максимальную выплату партнёру из состава. Этот показатель не зависит от выбранного прогноза; в режиме «Худшая» по нему также считаются МП, ЧП и целевая цена.

Добавление услуг открывает полный каталог города самого набора, без повторного переключателя городов. Поиск, фильтры цены/категории/партнёра и сортировка применяются совместно; добавлять можно несколько услуг подряд. Категории сопоставляются по наименованию с `data/pricing-categories.json` (Адеск → «Выручка New», снимок 13.10.2026). Неопознанные услуги сохраняются в «Без категории». Цена и выплата — текущий прайс CRM с локальными правками. Ограничений на первые 25/400 результатов нет.

Проверка ценообразования: `node scripts/test-pricing.cjs`, каталога: `node scripts/test-service-catalog.cjs`. Проверка источника: `node scripts/test-opiu-source.cjs [path/to/current-source.csv]`. Регрессионные проверки: `node scripts/test-opiu-calendar.cjs`, `node scripts/test-marketplace-history.cjs`, `node scripts/test-sales-analytics.cjs`, `node scripts/test-revenue-dynamics.cjs`.
