# Рабочая область: поиск новых партнёров WOWlife

Папка `partners/` — живой инструмент для подбора партнёров, которых у WOWlife ещё нет. Обновляется по мере новых прогонов.

## Что здесь

| Файл | Что это |
|---|---|
| `gap_analysis.md` | Анализ каталога: чего мало, что не хватает, что в тренде (по данным дашборда и протоколам встреч). |
| `existing_partners.csv` | Все 363 партнёра из дашборда: статус (active / inactive / stale), категория, города, выручка и активации, даты первой/последней активации. |
| `exclude_names.txt` | Чистые названия партнёров — список исключений для поиска. Генерируется из CSV. |
| `extra_partners.txt` | Партнёры из [таблицы Никиты](https://docs.google.com/spreadsheets/d/1vjVXyWcdbGmLJ5d9Zs9va0_2gMD1C8JdWUKssDvAQ8M) (листы активаций/услуг/контрагентов), которых нет в дашборде. Подхватывается `build_existing.py`. |
| `legal_entities.csv` | Юрлица/ИП контрагентов по партнёрам из той же таблицы — чтобы не подключить действующего партнёра под другим брендом. |
| `aliases.txt` | Кириллические/альтернативные написания партнёров («Скай Стрим» = Sky Stream), чтобы не подтянуть текущего партнёра под другим именем. Дополняйте. |
| `strategies.json` | 16 стратегий поиска × запросы для Яндекс Карт по двум городам. Добавляйте новые стратегии сюда. |
| `shortlist.md` | Шорт-лист приоритета A по стратегиям — с него начинать. |
| `candidates/*.json` | Найденные кандидаты по группам стратегий (A экстрим/вода/полёты/техно, B релакс/красота/премиум/медитативное, C творчество/гастро/обучение/визуал, D семья/романтика/загород/сезон). |
| `candidates/all.json`, `all.csv` | Сводный список после дедупликации и проверки на текущих партнёров. CSV открывается в Excel/Google Sheets. |
| `index.html` | Просмотрщик кандидатов с фильтрами (город, стратегия, приоритет, статус). На GitHub Pages: `/partners/`. |
| `scripts/build_existing.py` | Пересобирает список партнёров из `../index.html` (данные дашборда). |
| `scripts/scout.py` | Парсер Яндекс Карт / 2ГИС по стратегиям + сведение кандидатов + проверка названий. |

## Как обновлять

```bash
cd partners
python3 scripts/build_existing.py          # 1. после обновления дашборда — обновить список партнёров
#    новые партнёры из таблицы Никиты — дописать в extra_partners.txt и повторить шаг 1
python3 scripts/scout.py check "Название"  # 2. проверить, не партнёр ли уже
export YANDEX_GEOSEARCH_KEY=...            # 3. ключ «Поиск по организациям» (developer.tech.yandex.ru)
export DGIS_KEY=...                        #    ключ 2ГИС Places API (dev.2gis.ru) — даёт рейтинг и число отзывов
python3 scripts/scout.py search --group A  #    прогнать группу стратегий (или --strategy relax --city msk)
python3 scripts/scout.py merge             # 4. свести всё в candidates/all.json + all.csv
```

Поля кандидата: `priority` (A — рейтинг ≥4.7 и ≥50 отзывов / сильный бренд, B — хорош, но данные неполные, C — для покрытия категории), `rating`/`reviews` (если удалось увидеть), `gift_cert_ready` (уже продают свои сертификаты — быстрый онбординг), `visual_score` 1–5, `yandex_maps_query` (что вбить в Яндекс Карты для проверки), `maybe_partner` (похоже на текущего партнёра — проверить вручную), `status`/`comment` — для ведения воронки (new → contacted → negotiating → signed / rejected). Статус и комментарий можно заполнять прямо в `all.csv` или в JSON-файле группы: `merge` их сохраняет.

## Ограничения текущего прогона (18.09.2026)

- Из облачной среды Яндекс Карты, 2ГИС и сам wowlife.club закрыты сетевой политикой, поэтому первый список собран **через веб-поиск по подборкам и сниппетам** (Афиша, KudaGo, Собака.ru, VC, Telegram-подборки), а не парсингом карт. Рейтинг заполнен только там, где он был виден (≈15% записей). Перед выходом на контакт пробейте `yandex_maps_query` в Яндекс Картах — на это и рассчитан скрипт `scout.py search`, который запускается локально с API-ключом.
- Лимит веб-поиска сессии исчерпался: по стратегиям романтика/сезон в СПб, загород в ЛО и части гастро/обучения покрытие слабее — их стоит прогнать первыми при следующем обновлении.
- Список исключений сверен с таблицей Никиты (218 названий партнёров из листов активаций, услуг и контрагентов): все они в исключениях. Текстовая выгрузка Google Sheets обрезает длинные листы (~415 строк), поэтому при следующем обновлении стоит сверить полный список ещё раз.
- Категоризация текущих партнёров — по ключевым словам в названии; точность ≈90%.
